# Data

`airports.dat` and `routes.dat` come from the [OpenFlights](https://openflights.org/data.php) airport and route databases
(<https://github.com/jpatokal/openflights>), unchanged.

- Route data is as of **June 2014** (OpenFlights' route provider stopped updating it then), so it has historical value only.
- The OpenFlights databases are made available under the **Open Database License (ODbL 1.0)**
  (<https://opendatacommons.org/licenses/odbl/1-0/>); individual contents are under the Database Contents License.
  Airport data is derived from OurAirports and DAFIF, route data from Airline Route Mapper.

Source: OpenFlights.org. The network built from these files (airports as nodes, routes weighted by the number of
airlines) is used here for a non-commercial study; any derived database made public must stay under a free licence.
